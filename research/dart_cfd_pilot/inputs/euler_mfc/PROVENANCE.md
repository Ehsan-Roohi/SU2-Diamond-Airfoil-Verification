# MFC Euler source

The retained figures identify the case as an MFC Euler, slip-wall diamond
airfoil calculation at Mach 3 and 40 deg incidence. The very-fine field montage
is recorded at nondimensional time 13.5 and contains Mach, pressure ratio,
density ratio, and numerical-schlieren panels.

The complete montage, grid/vortex comparison, and separation diagnosis are
preserved alongside the two detector crops. The available raster files do not
embed an exact MFC commit or complete grid/configuration digest. Recover those
identifiers from the original run directory before using the fields for a
numerical validation claim. This limitation does not prevent their use as
fixed image inputs for the DART feasibility test.
