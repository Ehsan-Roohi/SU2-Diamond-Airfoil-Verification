# Published simulation results

This directory contains compact, reviewable evidence derived from checksummed
solver campaigns. Large native CFD fields remain in their archived data stores;
Git tracks figures, reduced tables, numerical-status markers, and provenance.

- [SU2 Mach-3 sharp diamond airfoil: AoA 0°, 4°, and 8°](su2_euler_m3_aoa_0_4_8/README.md)

Every campaign keeps numerical-gate status separate from field availability.
A retained field from a failed gate is not presented as a validated result.
